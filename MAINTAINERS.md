## Wanted

switchyard has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- the Streamable HTTP transport,
- the transparency test suite against more MCP clients and servers,
- approval holds for AgentRewind and AgentFuse,
- per-hop latency benchmarks.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
